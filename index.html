Why QR Codes are Inherently Dangerous

A QR code is a 2D binary matrix encoding up to 4,296 characters in a grid of black-and-white modules. Unlike hyperlinks rendered as readable text, the embedded payload — whether a phishing URL, a session-pairing token, or a malicious UPI VPA — is entirely invisible to the human eye prior to execution. The human visual system is not equipped to decode ISO/IEC 18004 matrices. QR Shield intercepts and decodes that payload before the device acts on it.

QRLJACKING ATTACK VECTOR
Without QR Shield — Standard Behavior
  1. ① Student scans flyer QR via WhatsApp → Linked Devices.
  2. ② Device sends pairing request to attacker's proxy domain (not WhatsApp servers).
  3. ③ Attacker's server relays token to real WhatsApp, completing session handshake.
  4. ④ Attacker gains persistent access to the student's WhatsApp session — all messages, contacts, and media.
With QR Shield — Intercept & Block
  1. ① Camera captures QR frame; payload decoded to raw URI string.
  2. ② Layer 3 instantly detects pair?token= and auth-token.xyz signatures.
  3. ③ Session quarantine flag raised — connection handshake blocked before transmission.
  4. ④ User notified with full threat report. No session data leaves the device.
Security Best Practices — Students
  • Never scan external QR codes using WhatsApp Linked Devices — only scan from the official WhatsApp Web page.
  • Always verify the domain URL after QR scan before proceeding.
  • Check for HTTPS padlock and confirm the apex domain (e.g., vtu.ac.in, not vtu-ac.in.xyz).
  • For UPI payments, confirm the payee VPA matches official college records before approving.
  • Use QR Shield's payload analyzer before acting on any campus-posted QR code.
